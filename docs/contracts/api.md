# API and events (draft)
/api/v1: auth, users, projects, versions, installations, instance state, files, desktop sessions, agent conversations/executions, providers, permissions, system calls, MCP connections. Sharing: POST /applications/{id}/share; GET /shares/incoming and /shares/outgoing; POST /shares/{id}/accept or /reject. Export/import, fork, publish, transfer and marketplace install use explicit POST operations. Use idempotency for acceptance/install, optimistic concurrency for drafts, pagination and structured errors. SSE agent progress; WebSocket versioned desktop events (application.generated/installed/updated, window.opened, file.updated, agent.started/tool.started/tool.completed/completed/failed, permission.requested). Never broadcast private events to other users.
