# .vibeapp format (draft)
Versioned ZIP: manifest.json, app.json, state.schema.json, initial-state.json, permissions.json, dependencies.json, assets/, workflows/, optional source/, migrations/ and README.md. Default initial state is template data, never live instance state. Optional selected data export requires explicit confirmation and secret scanning. Check archive limits, canonical paths, duplicate names, checksums, schema, license, compatibility and permissions before install. No code executes during inspection. No arbitrary backend scripts or unrestricted migrations. Published versions immutable; new installation grants independent. Signing is post-MVP.
