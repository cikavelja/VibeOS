# Development preview contract
This is a deliberately small implemented subset of the target architecture; the target contracts remain authoritative for the eventual product. Bearer tokens live in memory in the browser, expire after one hour, and are revoked on logout. All resources are filtered by ownership. Sharing sends a snapshot of the definition, never installation state. The recipient must accept before installation. Only five component types are supported, with no executable code or external calls. State saves explicitly. Project snapshots are immutable in this preview. There is no actual LLM, visual drag-and-drop, package export, marketplace, window manager, production identity, rate limiting, or PostgreSQL/Alembic support yet. The synchronous SQLite implementation is a development exception to the target async persistence architecture; migrate it in the relevant tasks. Do not expose this preview to the public Internet.
