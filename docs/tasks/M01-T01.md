# M01-T01 — Desktop shell and themes

Priority: MVP | Requirement: REQ-01-01

## Dependencies
M00-T05

## Objective and scope
Implement only desktop shell and themes in the frontend. Reuse existing contracts; inspect affected modules before adding new abstractions.

## Out of scope
Other task capabilities, unrelated refactoring, speculative dependencies, changing accepted contracts without an ADR.

## Acceptance criteria
- AC-01: Desktop occupies viewport, switches theme and wallpaper.
- AC-02: Invalid input and relevant failure paths are handled without silent success or unauthorized side effects.
- AC-03: Existing applicable regression tests pass and architecture/security constraints remain intact.

## Required verification
- Add automated tests that directly exercise AC-01 and AC-02; use integration or Playwright tests for cross-boundary/user-visible behavior and unit tests for pure logic.
- Run applicable build, lint, typecheck and regression checks from docs/TESTING.md.
- Record exact commands, exit codes, test names, commit and evidence per criterion. Manual checks, if needed, must include reproducible steps and observed results.
- Independent verifier writes docs/verification/M01-T01.md and proposes status change. Human review and required CI checks must pass before merge.

## Definition of done
All mandatory criteria pass; no unresolved critical/high findings; no skipped mandatory tests; documentation and registry updated. Status is authoritative in docs/tasks.json.

## Known limitations
- Theme (`midnight`, `daylight`, `high-contrast`) and wallpaper (`aurora`, `horizon`, `blueprint`, `monolith`) preferences are stored locally in validated, session-scope-isolated browser storage (`localStorage` keyed by `guest` or canonical authenticated username, falling back to in-memory session state with an explicit alert when browser storage is unavailable); server-side owner-scoped desktop preference persistence is deferred to `M02-T06`, and full desktop session/window restoration is deferred to `M01-T08`.
- Built-in application registry (`M01-T02`), multi-window lifecycle, bounds/drag/resize, focus/z-index, minimize/maximize/restore (`M01-T03`–`M01-T06`), and dock launcher/notifications (`M01-T07`) remain deferred to their designated `M01` tasks per [ADR 0002](../decisions/0002-preview-migration-strategy.md).
