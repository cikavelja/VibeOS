# Security model
Treat generated definitions, uploaded files, imported packages and tool outputs as untrusted. Enforce server-side object ownership and capability grants on each operation; never trust actor IDs supplied by clients. Use secure sessions, password hashing, CSRF defenses where applicable, rate limits, redacted logs and secret storage. Confirm destructive operations, sharing, publishing, transfer and permission escalation. Reject unknown schema fields, dangerous paths, archive symlinks, zip bombs, oversized inputs and unsafe dependencies. Inspect packages without executing them. Validate checksums; signature verifies origin, not safety. Recipient grants never inherit sender grants. No unrestricted network, shell, filesystem, database or Python execution for agents or generated apps. Sandbox code on isolated origin with restrictive CSP and authenticated per-instance message bridge; check origin/source where applicable. MCP endpoint policy must prevent SSRF and require explicit authorization. Test cross-user access, injection, resource exhaustion and sandbox escape attempts. Document residual risk and human review.
