# backend

FastAPI backend scaffold (`app/main.py`, `app/api/health.py`, `app/core/config.py`) alongside provisional development preview endpoints. Dependencies are pinned in `pyproject.toml` and locked reproducibly in `uv.lock` (`uv sync --locked`, `uv build`). See `docs/IMPLEMENTATION_PLAN.md` and `docs/decisions/0002-preview-migration-strategy.md`.
