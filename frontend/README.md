# frontend

React + strict TypeScript frontend (`src/main.tsx`, `src/desktop/DesktopShell.tsx`, `src/desktop/themes.ts`, `src/health/HealthScreen.tsx`, `src/services/health.ts`) alongside provisional development preview components. Dependencies are pinned in `package.json` and locked reproducibly in `package-lock.json` (`npm ci`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test`, `npm run e2e`). See `docs/IMPLEMENTATION_PLAN.md` and `docs/decisions/0002-preview-migration-strategy.md`.
